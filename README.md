# De Buena Masa - Panadería Artesanal

Repositorio del proyecto web de panadería y masa madre, desarrollado con HTML5, CSS3 (Grid y Flexbox), Bootstrap 5 y control de versiones con Git.

## 🔗 Enlaces del Proyecto
* **Repositorio en GitHub:** [https://github.com/matiascornet-debug/debuenamasa](https://github.com/matiascornet-debug/debuenamasa)

## 🛠️ Tecnologías Utilizadas
- HTML5 Semántico
- CSS3 (Responsive Design, Grid, Flexbox, Pseudo-clases y Transiciones)
- Bootstrap 5 (CDN, Navbar responsiva con menú hamburguesa y Carousel)
- Git & GitHub
